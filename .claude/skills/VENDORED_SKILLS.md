# Vendored agent skill packs

These third-party skill packs were vendored into `.claude/skills/` (and mirrored as
symlinks under `.agents/skills/`) so Cursor / Claude Code / Codex agents working in this
repo can discover them. They are independent of Mole's own project skills (`bugs`,
`mole`, `release-flow`, `release-notes`).

| Directory | Upstream | Author | License |
| --- | --- | --- | --- |
| `gstack/` | https://github.com/garrytan/gstack | Garry Tan | MIT |
| `pstack/` | https://github.com/cursor/plugins/tree/main/pstack | Lauren Tan (poteto) | MIT |
| `mattpocock/` | https://github.com/mattpocock/skills | Matt Pocock | MIT |

The **superpowers** set (https://github.com/obra/superpowers) is installed separately as
a Cursor marketplace plugin, so it is intentionally not vendored here.

## Notes

- `gstack/` holds the Cursor-flavored skill docs generated by `gstack`'s `setup --host cursor`.
  Skills that shell out to gstack's browser tooling (`/browse`, `/qa`, `/make-pdf`, ...)
  expect the gstack runtime (Bun + Playwright browsers) to be installed; the instructions
  are present regardless.
- To refresh a pack, re-run its upstream installer and re-copy the skill tree.
