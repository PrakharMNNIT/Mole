# Vendored agent skill packs

These third-party skill packs are vendored into `.claude/skills/` (and mirrored as
per-skill symlinks under `.agents/skills/`) so Cursor / Claude Code / Codex agents working
in this repo can discover them. They are independent of Mole's own project skills (`bugs`,
`mole`, `release-flow`, `release-notes`).

Skills are laid out **one directory deep** (`.claude/skills/<skill>/SKILL.md`), matching
how the agent runtime discovers skills. Because packs share skill names (e.g. `tdd`,
`review`, `teach`), each pack's skills are namespaced with a prefix.

| Prefix | Upstream | Author | License | Skills |
| --- | --- | --- | --- | --- |
| `gstack-*` | https://github.com/garrytan/gstack | Garry Tan | MIT | 53 |
| `pstack-*` | https://github.com/cursor/plugins/tree/main/pstack | Lauren Tan (poteto) | MIT | 45 |
| `mattpocock-*` | https://github.com/mattpocock/skills | Matt Pocock | MIT | 37 |

The **superpowers** set (https://github.com/obra/superpowers) is installed separately as
a Cursor marketplace plugin, so it is intentionally not vendored here.

## Notes

- `gstack-*` holds the Cursor-flavored skill docs generated by `gstack`'s
  `setup --host cursor`. Skills that shell out to gstack's browser tooling (`/browse`,
  `/qa`, `/make-pdf`, ...) expect the gstack runtime (Bun + Playwright browsers) to be
  installed; the instructions are present regardless.
- `pstack-*` internal `../principle-*` cross-references were rewritten to the prefixed
  directory names so relative links resolve.
- To refresh a pack, re-run its upstream installer and re-copy the skill tree with the
  same prefixing.
